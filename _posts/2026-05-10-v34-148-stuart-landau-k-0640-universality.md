# v34.148: Stuart-Landau 系统的 K≈0.640 普适性检验

> **摘要：** 本文回顾 ITLCT v34 框架从 DC-1570 到 DC-1669 共 100 轮研究的核心发现。C1 判据从经验规则升格为第一性原理证明的必要充分条件，网络拓扑指标 c_sat 在 5 个系统上验证了 c_sat×λ₂=K_sys 的形式不变性，非混沌系统的 CI_R 分类器经过 10 轮迭代后确立了 τ_R=1.60 阈值。当前，Stuart-Landau 系统作为 Type I-S 的第三次普适性检验即将执行数值验证。

## 一句话总结

**100 轮实证检验把 3D 三重判据压缩成了 1D——C1 是唯一站得住脚的系统整合判据。**

## 1. 框架简化：从 3D 到 1D 的数据驱动之路

这不是理论偏好，而是数据逼迫。

v33 框架有三条判据：动力学 (C1)、谱不可约 (C2)、因果 (C3)。经过 100 多轮实证检验：

- 动力学判据 → 12 轮全部失败 → C5：本体论上不存在
- 谱不可约判据 → 6 轮全部失败 → 历史记录
- 因果判据 → 全部失败 → 移除
- 统计不可约 (MI) → 100+ 轮逐步精炼 → **C1：必要且充分**

Φ* 被证明是一个稳态统计量，不是动力学变量。12 轮动力学测试全部证伪了线性弛豫假设。

---

## 2. C1 判据：从经验规则到第一性原理

C1 判据的核心很简单：Φ*_ss = ⟨MI⟩/H，通过 shuffled baseline + 3σ 阈值判断系统是否存在整合。

但"简单"背后是 100 多轮的陷阱识别与修正：

- **同构假阳性**：相同方程的未耦合系统在 c=0 产生虚假 MI
- **饱和效应**：Histogram MI 在 bimodal 分布下饱和，耦合响应消失
- **双估计器**：A 类用 Gaussian MI，C 类用 Histogram MI，B 类两者并用
- **MDSH 偏差模型**：E[MI] = B²/(2N·ln2)·κ + b_geom(B)，κ∈[1.08,1.10]
- **FP Risk Score**：0.25·S_eq + 0.20·κ(JSD) + 1.0·I(periodic)，6/6 正确分类

C1 最终形式化为一阶原理证明的必要充分条件：MI_true > 0 + 一致估计量 → C1 PASS；C1 PASS + FP Risk ≤ 0.25 + 5 个边界条件 → 真实整合。

## 3. 网络扩展：c_sat×λ₂=K_sys 的形式不变性

将 C1 从 N=2 扩展到 N>2 网络时，我们发现了一个优雅的关系：

**c_sat × λ₂ = K_sys**

其中 c_sat 是 Φ* 达到饱和阈值时的耦合强度，λ₂ 是图的代数连通性。

| 系统 | K_sys | 类型 | 来源 |
|------|-------|------|------|
| Lorenz | 2.045 | Type I (幂律) | DC-1624 |
| Rössler | 0.170 | Type II (Hill) | DC-1628 |
| Duffing | 0.465 | Type I (幂律) | DC-1633 |
| Hopf | 0.640 | Type I-S (正弦) | DC-1638 |
| Chua | 10.28 | Type III (阶跃) | DC-1630 |

K_sys 的缩放律：K = 2.28·λ_max^0.978（R²=0.9996，3 系统验证）

Chua 是 Type III 阶跃型系统，不适用缩放律（c_sat 数值不可行），改用 N=2 的 c_crit 代理。

## 4. 非混沌系统：CI_R 分类器的 10 轮进化

极限环系统的分类是最曲折的部分：

1. DC-1646：提出 ε 作为 Type I-A/I-B 分类参数
2. DC-1641-1645：FHN ε 扫描 → ε 分类器被连续 3 轮证伪
3. DC-1646：重构为 CI_R 波形分类器，τ_R=1.5
4. DC-1651：Rayleigh-VdP 等价假设被证伪 → CI_R 依赖于观测变量
5. DC-1654-1655：CI_R 数值偏差根因 → DC-1648 值被 FFT 方法高估 2-6x，废弃
6. DC-1656：VdP(μ=1) CI_R=1.414 < 1.5 但 MI 强烈振荡 → τ_R=1.5 在边界区域失效
7. DC-1658：VdP μ 扫描 → Gaussian MI 峰值响应模型被证伪（1/5 通过）

最终分类：Type I-S (CI_R < 1.2, Gaussian MI 单调, K≈0.640)；Type I-B (1.2-2.0, 需实验验证)；Type I-R (CI_R ≥ 2.0, PC 为主指标)。

## 5. Phase Coherence 的完整量化

对于 Type I-B/I-R 系统，Phase Coherence 取代 Gaussian MI 成为主要指标：

- c_sat,PC = K_PC · μ^1.47 · H_index / Gamma_0(μ)（R²=0.987）
- Gamma_0(μ) = 0.080 + 0.370·exp(-μ/1.20)（R²=0.992）
- H_min = 0.12 消除 c=0 假阳性的最小异质性
- K_PC = 3.203（CI_R < 2.0 时条件普适）
